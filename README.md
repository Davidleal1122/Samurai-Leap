# 🗡️ Samurai Leap

**Samurai Leap** is a fast-paced 2D action-platformer developed in **Godot Engine 4**.  
You play as a lone samurai scaling vertical towers, defeating shadow enemies with swift sword strikes and thrown bamboo. The game emphasizes responsive movement, precision attacks, and fluid animation in a pixel-art world.

---

## 🎮 Features

- ⚔️ Dual Weapon Combat: Switch between sword slashes and throwing bamboo.
- 🧱 Vertical Platforming: Wall jumps, downward strikes, and air momentum.
- 🔁 Checkpoint System: Fall? Respawn instantly at your last checkpoint.
- 🎨 Pixel Art + Smooth Animation: Built using Aseprite + AnimationTree.
- 🔊 Retro Sound FX: Jump, slash, and damage sounds generated via Bfxr.

---

## 🕹️ Controls

 Action            | Key           
-------------------|---------------
 Move              | Left / Right (← →) or A / D 
 Jump              | Spacebar      
 Attack (Sword)    | J / Right Click 
 Downward Attack   | S             
 Pause / Menu      | Esc
